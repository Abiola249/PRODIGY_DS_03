# 📊 Bank Marketing Customer Subscription Prediction

## 🔍 Project Overview
This project presents an end-to-end machine learning classification solution built to predict whether a bank customer will subscribe to a term deposit based on demographic, financial, and campaign interaction variables.

The goal was to help financial institutions improve marketing efficiency by identifying high-probability conversion leads before campaign deployment.

---

## 🎯 Business Problem
Banks often spend heavily on telemarketing campaigns without a clear understanding of which customers are more likely to convert.

This leads to:
- wasted marketing spend
- poor agent productivity
- low subscription conversion rates

This project was designed to build a predictive analytics solution capable of identifying customers with the highest subscription probability.

---

## 🗂️ Dataset Information
- Source: UCI Bank Marketing Dataset
- Total Records: 45,211
- Total Features: 17
- Data Type: Structured Banking Customer Data

---

## 🛠️ Tools & Technologies Used

---

## ⚙️ Project Workflow
### 1. Data Cleaning & Preparation
- Encoded categorical variables
- Handled class imbalance
- Checked null values and duplicates

### 2. Exploratory Data Analysis
- Customer demographic trend analysis
- Campaign response distribution
- Call interaction variable analysis

### 3. Feature Engineering
- Built transformed analytical features
- Prepared train-test modeling data

### 4. Modeling Execution
- Decision Tree Classifier
- Hyperparameter tuning with GridSearchCV
- 224 parameter combinations tested

### 5. Dashboard Reporting
- Interactive Power BI dashboard built for stakeholder decision support

---

## 📈 Key Insights & Findings
- Achieved 89.9% prediction accuracy
- Achieved ROC-AUC score of 0.90
- Call duration contributed approximately 48% of total predictive power
- Customers staying beyond 5 minutes on call had significantly higher conversion probability

---

## 💡 Business Recommendations
- Prioritize long-engagement customers for conversion campaigns
- Redesign telemarketing scripts for early retention
- Deploy predictive lead scoring before outbound campaign targeting

---

## 🚀 Outcome / Impact
This project demonstrates how machine learning can reduce inefficient campaign spending and improve customer targeting precision in financial marketing operations.
